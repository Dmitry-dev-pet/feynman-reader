Feynman Reader Uploader

Privacy Policy

Feynman Reader Uploader is an owner-operated utility used to publish and maintain educational media on the Feynman Reader Study Media YouTube channel.

Effective September 29, 2026 Last updated September 29, 2026

Scope

This policy explains how the Feynman Reader Uploader uses information obtained through Google and YouTube APIs. The tool is not offered as a multi-user service and does not create public user profiles.

Information the tool accesses

After the channel owner authorizes the app, it can access:

  • basic YouTube channel information, including the channel ID and title;
  • video metadata, privacy status, and playlist membership;
  • the video files and metadata that the channel owner explicitly selects for upload; and
  • OAuth credentials needed to keep the authorized session active.

How information is used

The information is used only to authenticate the channel owner, upload selected videos, update video titles and descriptions, manage playlist membership, and run read-only channel audits or synchronization checks.

The tool does not use Google user data for advertising, profiling, credit decisions, or any purpose unrelated to these channel-management functions.

Storage and security

OAuth credentials are kept on the channel owner's computer and, when automation is enabled, in a restricted GitHub Actions Environment secret. A workflow may write the credential to a temporary file on a GitHub-hosted runner for the duration of a run. Credentials are not committed to the public repository.

No separate advertising, analytics, or user-profile database receives Google user data from this tool.

Sharing

Google user data is not sold. It is not shared with third parties except as necessary for Google and YouTube to provide their APIs and for GitHub Actions to execute an owner-requested automation run.

Google API Services User Data Policy

Feynman Reader Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, deletion, and revocation

OAuth credentials are retained only while the channel owner wants the tool to have access. The owner can revoke access at any time from Google Account connections. Local credentials and the corresponding GitHub secret can then be deleted or replaced.

Video and playlist changes made through the YouTube API remain part of the YouTube channel until the channel owner changes or deletes them in YouTube.

Contact

Questions about this policy or requests concerning the tool can be submitted through the Feynman Reader issue tracker.
